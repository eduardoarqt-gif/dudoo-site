# Site Dudoo (dudoo.app.br) — regras de design para páginas novas

- Páginas utilitárias (baixar, pagar, obrigado, pagamento não concluído, etc.): **sempre tema claro**, mesmo design das telas do Dudoo Lite (fundo #F7F4EC, cartões brancos, borda #DCD3B9, destaque #7E6A3F, fontes Jost e Sora). **Nunca** tema escuro nem `prefers-color-scheme: dark`.
- Copie a base de `obrigado/index.html` ou `baixar/index.html` ao criar uma página nova.
- Todo campo pede só o necessário e diz claramente o que digitar.
